#Exercícios da Faculdade

Bem-vindo(a) ao meu repositório de exercícios práticos da faculdade!

Este espaço é dedicado a armazenar e organizar todos os projetos e atividades que desenvolvo ao longo do meu curso. O principal objetivo é documentar meu progresso, registrar minha evolução nas diferentes disciplinas e criar um portfólio com os desafios que superei.

Sinta-se à vontade para explorar as pastas e acompanhar minha jornada de aprendizado.

## Estrutura do Repositório

Cada pasta representa uma matéria específica e, dentro dela, você encontrará os exercícios correspondentes.

- **/Nome-da-Materia-1**
  - /Exercicio-01
  - /Exercicio-02
- **/Nome-da-Materia-2**
  - /Exercicio-01
- ... e assim por diante.

Obrigado pela visita!
